# ⚡ PWA Meter Stand Reader - SMKN 1 Purbalingga

Aplikasi Pencatat Stand Meter Listrik Panel Depan dan Belakang berbasis Progressive Web App (PWA) yang dilengkapi dengan kecerdasan buatan **Gemini AI OCR Vision** untuk membaca angka meteran analog secara otomatis serta terintegrasi langsung ke **Google Sheets**.

---

## 🛠️ Fitur Utama

- 📸 **Pembacaan AI OCR (Gemini API)**: Otomatis membaca nilai Ampere R, S, T, dan Voltase dari foto meteran analog.
- ⚡ **Kalkulasi Otomatis**: Menghitung rata-rata Ampere dan total beban beban secara real-time.
- 📊 **Rekap Harian & Bulanan**: Visualisasi data ringkasan harian dan analisis stabilitas beban bulanan.
- ☁️ **Google Sheets Database**: Integrasi mudah menggunakan Google Apps Script.
- 📱 **PWA Ready**: Dapat diinstall di HP (Android/iOS) dan diakses secara offline.

---

## 🚀 Cara Membuka & Deploy di Vercel

1. Buat repositori baru di [GitHub](https://github.com) dan *upload* semua file di atas.
2. Login ke [Vercel.com](https://vercel.com) menggunakan akun GitHub.
3. Klik **New Project**, pilih repositori `pwa-stand-meter`.
4. Klik **Deploy** (Tanpa perlu konfigurasi build/framework khusus).
